# 删除历史关联清理 V55（基于 PR #35 / V54）

## 范围和入口

复用 V54 的 `td_business_hidden_v54`、原记录快照、旧审计隐藏标记及 `td_hide_audit_batch_v54` 原子写入。V54 员工明细删除入口保持原有单条/批量语义，不自动变成关联删除。

管理员「删除历史」合并订单删除日志与 V54 业务删除标记，按业务表和 UUID 去重。单条、勾选多条或全选后必须先读取数据库生成的关联预览，列出全部将退出业务的记录、已删除记录、受保护共享记录及原因。手机端采用卡片、24px 多选框、至少44px按钮。审计记录在「删除历史」仍保留，普通历史查询则复用 V54 统一过滤。仅旧订单历史隐藏继续提供原“恢复显示”按钮；已存在 V54 业务删除标记的不提供局部恢复，避免只恢复订单造成关联状态不一致。

## 关联规则

| 对象 | 自动关联条件 | 保护边界 |
| --- | --- | --- |
| 订单 | 明确选择真实订单 UUID | 不从客户、包裹或收款反向推断其他订单 |
| 包裹 | `order_id` 和已有正式结构化 `[TD_ORDER_IDS:uuid,...]` | 共享包裹仍有其他未删除订单时保留；不完整 UUID 标记、客户不匹配时保留；明确选择包裹可单独清理该业务，但不删除父订单 |
| 取件 | `parcel_id` 指向删除包裹，或明确选择 | 不按姓名、电话、时间、金额推断取件批次；不重置库存 |
| 取件结算 | `td_pickup_batch_items` 的全部包裹都在本次范围或已被 V54 标记 | 仍包含正常包裹的共享结算保留；明确选择共享结算也不会删除其正常包裹 |
| 结算收款凭证 | `batch_id` 指向专属结算 | 仅增加退出业务统计标记；原始凭证永久保留 |
| 收付款 | 订单 `order_id` 或凭证 `payment_id`，或明确选择 | 仍关联其他正常结算或订单的共享流水受保护；客户相同的独立收款不自动进入范围；客户不匹配的凭证关系受保护 |
| 客户 | 相关客户已无其他正常订单、包裹、取件、流水或结算 | 共享客户保留；单独选客户不会级联清空全部业务 |
| 批次包裹关系 | 批次和包裹的真实组合键 | 原关系不修改、不删除；随整批退出普通业务查询，在预览和审计中保留 |

没有结构化关系的历史记录不会按备注相似、同客户、同金额等条件猜测归属。原业务已经物理缺失的历史日志会拒绝清理，并说明不能仅从快照推断；日志本身不会删掉。

## 数据库保证

完整增量 SQL：[`sql/deletion-history-relations-v55.sql`](../sql/deletion-history-relations-v55.sql)，前置条件为 V54 已安装。

- `td_preview_history_delete_v55(p_entries)` 在数据库验证激活、未删除管理员，返回15分钟有效且绑定当前操作者的随机预览 token。服务端保留所选根业务、全部影响快照和共享保护决策。
- `td_confirm_history_delete_v55(p_token,p_reason,p_confirmation)` 再次验证管理员，原因至少3字，确认文字必须为 `确认关联删除`。不能靠前端布尔值跳过确认。
- 确认事务锁定预览和管理员身份；以 SHARE ROW EXCLUSIVE 锁短暂阻止相关业务表及 V54 标记表的并发写入，重新计算完整计划。记录、金额、关系或删除状态发生变化时整批拒绝，必须重新预览。锁范围较广，适用于管理员低频清理；应避开业务高峰。
- 核心五类标记继续由 V54 RPC 写入；新增结算和收款凭证类型仅扩展同一 V54 标记表。任何后续写入错误会连同 V54 标记、审计标记及预览消费状态全部回滚。
- 同一 token 成功后重试返回原结果；重新预览已清理业务只增加尚未存在的标记，不重复改库存、金额或原始账目。原记录完全没有 UPDATE/DELETE 操作。
- 实现放在未暴露的 `td_private`，公开 RPC 为 SECURITY INVOKER。私有实现为受控 SECURITY DEFINER，固定空 search_path，撤销 PUBLIC/anon 执行权限；内部计划函数不可由 authenticated 直接调用。预览审计表启用 RLS，无客户端表权限。
- 一次最多5000个根记录、20000条关联预览；超限直接拒绝，不拆成部分成功的批次。

## 页面与统计

V54 的刷新逻辑继续统一过滤五类业务标记；V55 结算标记通过原 `td_business_hidden_ids_v54()` 自动返回。普通业务、记录查询、员工明细、CSV/PDF 的日/周/月/年统计排除已标记业务。期间运费查询也读取并过滤凭证 ID，同时整批标记排除对应结算及所有凭证。原始财务数据仍可由授权审计查询追溯。

前端新增两项 RPC 允许列表及 V54 标记表的只读代理路由；未开放对审计表的写入或删除。
