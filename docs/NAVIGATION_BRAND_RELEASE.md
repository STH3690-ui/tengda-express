# V3.2 独立导航主页与全局按钮优化

## 导航

登录后进入 `#/home` 独立工作主页：使用未修改的 `icon-512.png` 黑金狐狸Logo、站名、账号显示和基于既有已加载数据的三项简洁经营概览。取消旧顶部横向菜单。

管理员主页提供14个入口：客户、包裹、到站取件、订单、收款欠款、统计报表、历史记录、员工录入、员工管理、录入明细、记录管理、包裹查询、站点地址、系统设置。收款欠款和记录管理是导航入口集合，复用原流水、取件欠款、删除历史及归档页面，不新增账务逻辑。员工录入仅展示已授权的录入项目。

旧页面ID（dashboard/customers/orders/parcels/query/pickups/payments/records/deletions/cleanup/staff/staffAudit/stations）全部保留，支持对应 `#/页面ID`；客户编辑、站点编辑、员工授权和订单/包裹照片详情增加可返回的URL。所有功能页左上角“返回主页”，详情/编辑另有“返回上一页”。

管理员专属账号、员工明细和记录管理仍只向owner展示；员工财务、取件、记录入口根据既有permissions显示。前端导航不是安全边界，服务端原授权与RLS保持不变。系统设置仅含现有账号操作和本设备大字偏好，没有新增后台设置权限。

## 返回与草稿保护

统一使用浏览器History API。站内按钮、浏览器后退/前进以及TWA的浏览器历史返回共用路由；取消后退时恢复原历史位置，并防止连续返回的恢复竞态。

离开有未保存表单、取件输入、权限选择或待上传照片的页面时确认。后台读取数据触发同页重绘时保留内存草稿和File对象；数据读取失败时不覆盖有草稿的页面。输入内容和照片不写入URL、history.state、localStorage或新数据库表；只有本设备大字开关使用localStorage。

原写入成功路径只增加UI状态清理钩子，失败保留输入；现有异步提交期间暂停站内离开，完成后解除。刷新/关闭页面使用beforeunload提示。系统强制结束进程不属于可保证的草稿持久化范围。

## 招牌与按钮

`brand-interface.css` 统一黑、金、白，导航卡片黑底金边圆角、各自金色SVG，加入简洁速度线；原图标文件不改变。手机3列、700px起4列、1000px起5列。

统一普通按钮、主按钮、次按钮、表格与异步区域按钮、登录/注册、编辑/上传/筛选/取消/全选/确认/返回、弹窗以及导出报表窗口的按钮语言。触摸目标至少44px，按下轻微金色反馈、键盘焦点可见；危险操作保留原二次确认并使用红色警示，停用和归档按钮也标记危险样式。对话框限制在视口内，宽表继续使用内部横向滚动。

## 变更边界

本次只修改HTML/UI、导航JS、品牌CSS、静态打包和测试。没有SQL、迁移、RLS、RPC签名/参数、收付款/欠款计算、删除机制或统计计算变更。原始图标摘要保持 `e1117c224831e22444ed66789a0152b455b7fdc835d54788955cf09f6f11aedb`。

Android `com.tengda.express` 包名、版本配置、公钥证书、DAL与私钥均不改动。已安装TWA从原站加载新界面，无需重签APK。未来Android版本继续使用原密钥。
