- [ ] 确认 V57 capabilities.version=57，保存测试库备份；只用新建专用测试客户、运单和有明确权限的账号，保留已有记录。
- [ ] 分别准备管理员、可入库/取件/收款员工、不可收款员工、停用账号；不在截图或验收记录保存密码、令牌、电话等个人信息。

## iPhone Safari 与添加到主屏幕 PWA

- [ ] Safari 首次打开扫码页不自动请求摄像头；点击开启后请求权限，拒绝时有清楚提示，允许后显示后置摄像头画面。
- [ ] 将测试站点添加到主屏幕后独立启动，完成允许/拒绝/系统设置撤销授权再恢复；不要求 iOS 不支持的震动或手电筒能力。
- [ ] 支持的设备可切换前后摄像头；有手电筒能力时可开关，无能力时界面正确降级。
- [ ] 锁屏、切后台、切业务页、关闭 PWA 后摄像头指示关闭；返回后需要再次点击开启，既有清单/未确认状态符合提示。
- [ ] 竖屏、横屏、刘海/安全区、键盘弹起、放大字体下可看到扫码结果、金额和确认按钮。
- [ ] 拍照/选图上传成功；取消、权限拒绝、上传失败可恢复，不生成第二份包裹。

## Android Chrome 与 TWA

- [ ] Chrome 与测试 TWA 分别执行摄像头允许/拒绝、后置优先、摄像头切换、手电筒能力检测。
- [ ] TWA 地址与关联域名确为测试站点，原狐狸图标和正式包 `com.tengda.express` 的签名/安装不被覆盖。
- [ ] 返回键、切后台、锁屏、横竖屏、系统回收进程后，摄像头释放，恢复后没有自动取件或收款。
- [ ] USB 与蓝牙 HID 各测一轮：Enter 结束符、连续输入、重复码、断连重连；编辑重量/金额/客户输入框时不被全局扫码监听抢走输入。
- [ ] 手机上原登录、普通入库、普通取件和历史页面仍可使用；停用或无权限账号不能通过扫码入口绕过授权。

## 真实快递标签与业务验收

| 场景 | 操作与预期 | 结果/证据 |
| --- | --- | --- |
| 基础标签 | 用真实 Code128、Code39、EAN13、EAN8、QR 标签核对解码文本与人工读数完全一致；ITF、Codabar、UPC、DataMatrix、PDF417 单独记录设备与样本结果 | 待填 |
| 复杂光学 | 分别测试小码/长码、折痕、反光、弯曲、暗光、斜角、远近距离、多码同框；不可识别时可手工输入，不能误选相邻标签 | 待填 |
| 客户匹配 | 登记过的运单精确返回真实客户；未登记运单不猜客户，入库需搜索并明确选中；同名客户人工辨别，普通员工电话仍屏蔽 | 待填 |
| 扫码入库 | 专用客户两单分别填件数/重量，确认后各产生一条包裹；混合非法客户时逐条报告，失败项保留；图片失败不重新插入包裹 | 待填 |
| 连续取件 | 同客户三单连续加入；其他客户、已取件、已删除及历史歧义码不自动加入；移除其中一单后金额同步更新 | 待填 |
| 重复扫码 | 镜头停留同一码、HID 重复码、大小写/首尾空白及多设备同时提交，不重复入库/取件/收款；历史重复显示人工核对提示 | 待填 |
| 运费/欠款 | 两单总重 2kg、单价 7,000、实收 5,000：确认框与服务端均应收 14,000、欠款 9,000；库存归零、批次两条明细、原收款凭证仅一份 | 待填 |
| 确认/权限 | 扫描本身不收款；取消确认不写账；未授权收款员工不能提交实收；确认后快速双击不重复处理 | 待填 |
| 弱网/丢响应 | 确认前断网、提交后丢响应、刷新恢复分别验证；保留同一请求 UUID 核实结果，不能因超时直接重建请求 | 待填 |
| 回滚 | 配合自动化的故障注入证据核对库存、批次、流水、收款凭证、审计一致回滚；不在正式库注入故障 | 待填 |

真实标签可遮盖姓名、电话和地址；样本运单不得关联正式业务数据。照片及证据保存到受控位置，不提交客户标签到公开仓库。
