# V62.2 紧凑入库界面

仅改界面/交互，复用现有相机拍照/OCR、客户匹配、入库、取件、权限与请求恢复函数；不改数据库SQL、业务计算或识别阈值。

默认顺序：返回图标/扫码入库/主页图标→相机预览与金框→相册/圆形快门/手电筒→折叠客户选择→姓名/电话并排→件数/总重量并排→单行备注→金色确认入库。删除默认冗长说明、重复标题/按钮/边框，隐藏本页大品牌头和会话工具栏，其他页面保持原样。

首次点快门开启相机，再点沿用原高清抓拍；相册使用文件选择器，不强制打开系统相机。手电筒按设备能力启用，不支持时禁用。确认按钮在相机预览中会先停止预览再调用原人工确认逻辑，沿用原确认框/权限/请求保护。OCR自动入库逻辑不变。

客户选择默认折叠，展开后输入姓名或电话自动搜索，260ms防抖；新查询或清空输入立即使旧响应失效，选择后自动收起。旧组件/扫码清单也取消独立搜索按钮，改为输入搜索。搜索角色过滤不变。

高级相机控制、识别文字、来源与最近记录折叠；旧版识别与批量扫码默认折叠，展开时隐藏主表单，避免双份表单。原旧版功能、照片保存和免OCR入库仍可使用。

自动测试：320/360/390/430宽度的布局顺序、两列、可触达尺寸、横向不溢出、常见视口确认按钮可见；搜索防抖/旧响应防护；选择后收起；相册/设备手电筒模拟；相机启停和原入库载荷一致；旧版开关只显示一份表单。保留V58/V62/V62.1完整浏览器和PostgreSQL/OCR回归。手机视口/WebKit不是iPhone或Android硬件实测；硬件相册/对焦/手电筒仍需实机确认，不能虚报。

本次无正式SQL迁移、业务数据写入/删除、照片清理、Restore或新增付费服务。
